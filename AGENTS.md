# Repository workflow

After completing and verifying an authorized update in this repository, commit only the changes for that task and push the commit to the current branch on the 1gbc/DangoMusic-GTNH GitHub repository. Follow any per-task instructions about review or publishing. Respect branch protection and never force-push. If the push fails, report the reason and the local commit.

For versioning and release work, follow [Versioning and releases](CONTRIBUTING.md#版本号与发布). Keep incremental development versions and their JARs local. Push a development iteration only when the user separately requests source synchronization, and reserve GitHub Releases for approved formal versions.
